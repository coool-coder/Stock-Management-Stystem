# Development workflow

Each phase should be completed and tested before the next phase begins.

1. Define business rules.
2. Add/update Flyway migration.
3. Implement entities and repositories.
4. Implement services and transaction rules.
5. Add DTOs and validation.
6. Add REST controllers.
7. Add frontend feature, routes and forms.
8. Add tests.
9. Run integration checks.
10. Update documentation.
